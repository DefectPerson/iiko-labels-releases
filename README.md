# Этикетки iiko для Windows

[**Скачать установщик**](https://github.com/DefectPerson/iiko-labels-releases/releases/latest/download/IikoLabels-Setup.exe)

Приложение для печати этикеток на АТОЛ DD340: название, время выдачи, срок годности и условия хранения. Поддерживает собственные списки, разные количества этикеток и редактор макета.

## Установка

1. Скачайте и запустите установщик на Windows 10/11 (64 бита). Python устанавливать не требуется.
2. Установите драйвер принтера и подключите принтер.
3. При первом запуске укажите подключение к iiko или загрузите файл каталога из другой копии приложения.

Для переноса каталога откройте на исходном компьютере «Настройки → Подключение и перенос каталога → Скачать каталог». На новом компьютере выберите «Загрузить каталог». Файл содержит названия, сроки и температуру, без пароля подключения.

## Обновления

Установленные копии проверяют новые версии при запуске и каждые пять минут. Обновления загружаются автоматически и применяются после завершения печати и работы в открытых окнах. Каталог, списки и макет сохраняются. Если приложение закрыто или компьютер выключен, проверка произойдёт при следующем запуске.

Здесь публикуются только установщики и подписанные сведения об обновлениях. Личные настройки и каталоги пользователей сюда не загружаются.

Первый установщик пока не имеет сертификата издателя Windows: система может показывать неизвестного издателя. Подпись обновлений проверяется самим приложением.
